# Levli v0.6

גרסה זו מחליפה את Yahoo Finance ב-Twelve Data כמקור להיסטוריית המחירים החודשית.

## זרימת העבודה
1. העלאת Finviz Custom CSV.
2. סינון פונדמנטלי לפי כללי Levli הקיימים.
3. הורדת מחירי `1month` מ-Twelve Data רק למניות שעברו פונדמנטלית.
4. חישוב MA50 חודשי אמיתי.
5. בדיקת מגמת MA50 ב-24 הנקודות החודשיות האחרונות.
6. הצגת המניות שעברו עם Levli Score.

## הגדרת המגמה הטכנית ב-v0.6
- MA50 הנוכחי גבוה מה-MA50 בתחילת חלון 24 החודשים.
- שיפוע לינארי חיובי.
- לפחות 18 מתוך 23 השינויים החודשיים ב-MA50 אינם שליליים.
- המחיר החודשי האחרון מעל או נוגע ב-MA50.

## Secrets
ב-Streamlit יש להגדיר:

```toml
TWELVE_DATA_API_KEY = "YOUR_KEY"
```

אופציונלי, אם לחשבון יש מכסה גבוהה מ-8 API credits לדקה:

```toml
TWELVE_DATA_CREDITS_PER_MINUTE = 55
```

ברירת המחדל היא 8, המתאימה לתוכנית Basic/Free בזמן הכנת v0.6.

## הערת מכסה
`/time_series` צורך קרדיט אחד לכל symbol. בתוכנית Basic/Free קיימת מכסה של 8 API credits לדקה, ולכן סריקה של כ-166 מניות יכולה להימשך כ-20 דקות. האפליקציה מבצעת batching והמתנה אוטומטית בין הקבוצות.
