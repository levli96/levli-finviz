# Levli v0.8

גרסה זו שומרת ללא שינוי את סינון Levli הקיים:

1. סינון פונדמנטלי מ-Finviz.
2. MA50 חודשי במגמת עלייה בכ-24 החודשים האחרונים.
3. SMA50 יומי בכשנת מסחר + מחיר מעל/נוגע בממוצע + לפחות 5 חציות מאושרות.

חדש ב-v0.8:
- עמודת **Industry** מתוך Finviz מופיעה בתוצאות.
- **Levli Score** מוצג בטווח ⭐ עד ⭐⭐⭐⭐⭐ ומבוסס על האיכות הפונדמנטלית בלבד.
- הרשימה הסופית ממוינת לפי Levli Score מהגבוה לנמוך.
- הנתונים הטכניים נשארים תנאי מעבר/מידע ואינם מוסיפים כוכבים.
- IPO Date אינו נדרש עוד בקובץ Finviz, משום שהיסטוריית המחירים נבדקת בפועל דרך Twelve Data.

ה-API key של Twelve Data נשמר ב-Streamlit Secrets תחת `TWELVE_DATA_API_KEY`.
