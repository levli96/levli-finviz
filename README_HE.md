# Levli v0.5

גרסה זו משלבת:
1. Finviz Custom CSV לסינון הפונדמנטלי.
2. Yahoo Finance דרך yfinance להיסטוריית מחיר חודשית.
3. חישוב MA50 חודשי אמיתי.
4. בדיקת מגמת MA50 על 24 נקודות חודשיות אחרונות.
5. מחיר חודשי אחרון מעל או נוגע ב-MA50.

## הגדרת מגמה ברורה ב-v0.5
- MA50 בסוף החלון גבוה מ-MA50 בתחילתו.
- שיפוע לינארי של MA50 בחלון חיובי.
- לפחות 18 מתוך 23 השינויים החודשיים ב-MA50 הם אפס או חיוביים.
- המחיר החודשי האחרון >= MA50 החודשי האחרון.

היסטוריה ארוכה יותר מ-24 חודשים נדרשת רק כדי לחשב את MA50 עצמו; חלון בדיקת המגמה הוא כ-24 חודשים.
