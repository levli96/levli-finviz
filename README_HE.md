# Levli Finviz v0.2
Finviz מבצע את הסינון הפונדמנטלי על אלפי ניירות. רק המועמדות שעברו נבדקות טכנית על היסטוריה יומית של כ-2.3 שנים.

בדיקה טכנית:
- מגמת עלייה בגרף חודשי לאורך כ-2 שנים.
- MA50 יומי עולה מול MA50 לפני 20 ימי מסחר (ניתן לשינוי).
- מחיר נוגע ב-MA50 או מעליו; ברירת מחדל לנגיעה: עד 2% מתחת ל-MA50.

FMP משמש ב-v0.2 רק לקריאת היסטוריית מחיר של המועמדות, לא לפונדמנטל.
